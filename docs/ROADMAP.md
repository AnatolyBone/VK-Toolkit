# VK Toolkit Roadmap

## v0.1.x

- Dialog exporter
- CMID / message debug tools
- Photo helper
- Basic UI tweaks

## v0.2.x — Modular architecture

- Core module manager
- Independent feature modules
- Better settings system
- Wall tools
- Profile tools
- Media tools

## v0.3.x

- Plugin API
- Custom CSS manager
- Theme support
- Archive viewer for exported dialogs

## v1.0

- Stable VK Toolkit platform
- Firefox support
- Public module documentation

## v0.5.x — Attachments

- Structured attachment metadata
- CMID-linked filenames and download report
- Photo, document, audio, voice-message, video and sticker support
