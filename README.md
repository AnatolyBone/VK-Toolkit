# VK Toolkit

Набор локальных инструментов для актуального VK (`vk.ru`, с поддержкой старого `vk.com`), собранный как модульное браузерное расширение.

> Проект не связан с VK и не является официальным расширением VK. Все функции работают локально в браузере пользователя.

## Возможности

### Диалоги
- полная выгрузка истории переписки с принудительной подгрузкой старых сообщений;
- канонический экспорт на основе данных VK без DOM-дублей;
- проверка диапазона и пропусков `CMID`;
- экспорт в HTML, JSON, Analysis JSON и TXT;
- локальное сохранение прогресса выгрузки.

### ID / debug
- отображение `CMID` / message ID на сообщениях, если идентификатор доступен в DOM VK;
- копирование ID по клику;
- отображение и копирование `peer_id` текущего диалога;
- отображение ID для URL вида `/id123`, `/club123`, `/public123`.

### Фото
- кнопка `↗ Макс.` при наведении на крупное изображение;
- открытие максимального URL, который VK реально передал текущей странице через `srcset`, `data-original`, `data-src` или CDN URL.

### Интерфейс
- скрытие Клипов;
- скрытие Историй;
- скрытие блоков рекомендаций;
- более компактные отступы левого меню.

Все модули можно независимо включать и выключать в popup. Настройки сохраняются через `chrome.storage.sync`.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions/`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите корневую папку проекта, где находится `manifest.json`.
6. Обновите открытую вкладку VK (`F5`).

## Поддерживаемые браузеры

Сейчас проект ориентирован на Chromium-браузеры с Manifest V3: Chrome, Edge, Brave и совместимые.

## Ограничения

VK — SPA, а внутренние классы, DOM-структура и сетевые ответы сайта могут меняться. Поэтому UI-функции сделаны как независимые отключаемые модули, а экспорт переписок использует сетевые данные VK с DOM как резервным источником во время сбора.

Расширение не пытается получать приватные оригиналы файлов, которых VK не передал странице, и не отправляет экспортированные данные на внешний сервер.

## Roadmap

- обновление ранее сохранённого архива диалога без полной повторной выгрузки;
